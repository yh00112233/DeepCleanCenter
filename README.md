# DeepClean Center

Windows 深度清理工具，用于扫描并选择性处理缓存、临时文件、大文件、大型软件目录、启动项、计划任务、服务、浏览器策略和疑似捆绑/流氓软件项。

## 主要功能

- 按软件或系统区域分组展示扫描结果
- 左侧显示分组汇总，右侧逐项选择具体清理项
- 为每个项目显示扫描原因、默认选择理由、风险等级和处理动作
- 支持导出 CSV 清单
- 支持打开项目位置
- 支持隔离可疑文件/目录
- 支持调用 Windows Defender 快速/全盘扫描

## 安全策略

- 普通缓存、日志、转储等可重建项目会默认勾选
- 大型软件目录、旧版本目录、容器数据盘、AI 模型目录等不会默认勾选
- 涉及启动项、计划任务、服务、代理、hosts、PUP 候选项时需要人工确认
- 删除失败或正在占用的文件会跳过，不强制破坏系统文件

## 运行方式

双击 `DeepCleanCenter.exe`。

如果使用源码运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\Clean_PC_Selectively.ps1
```

## 注意事项

建议先扫描并展开分组查看原因，再处理选中项。对于“人工确认”的项目，优先使用官方卸载程序或打开位置确认用途，不要盲目删除。
